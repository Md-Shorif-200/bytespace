# ByteSpace

A modern landing page and authentication UI built with Next.js and Tailwind CSS.

Live demo: https://bytespace-sharif.vercel.app/

## Overview

ByteSpace is a clean and responsive educational platform landing page with:
- hero section
- course showcase
- learning path section
- platform overview
- join-as-creator section
- client reviews
- login and register pages

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Hook Form
- React Hot Toast

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Production Build

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

## Notes

This project focuses on a clear UI structure, reusable section components, and a polished frontend layout for a learning platform.
